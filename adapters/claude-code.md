# Claude Code Adapter

Install the `janef-one` directory under the user's or project's Claude Code skills location supported by the current Claude Code version.

Invoke `/janef-one` when explicit activation is desired.

JANEF ONE should respect `CLAUDE.md`, repository instructions, permissions, available tool schemas, and the current git worktree. It should not hard-code tool contracts from leaked prompt snapshots when the live harness exposes a different contract.
