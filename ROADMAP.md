# Roadmap

JANEF ONE v1.0.0 establishes the stable kernel and release gates. Future work should be evidence-driven rather than feature-count driven.

## Near term

- Cross-runtime conformance fixtures for major Agent Skills hosts.
- Larger end-to-end behavioral benchmark corpus.
- More adversarial Skill Firewall fixtures and provenance checks.
- Optional signed state/evidence backends.
- Machine-readable capability negotiation for adapters.
- Reference WorkGraph visualizer without coupling the kernel to a UI framework.

## Non-goals

JANEF ONE will not become a mechanism for bypassing host policy, permissions, safety controls, or unavailable tools. It will not bundle third-party system-prompt corpora into public releases.
