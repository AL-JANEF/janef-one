# Support

Use GitHub Discussions for usage questions and design proposals. Use Issues for reproducible bugs and feature requests. Use GitHub private security advisories for vulnerabilities or sensitive security reports.

Before filing a bug, run:

```bash
python3 scripts/validate.py
python3 scripts/test_runtime.py
```

Include your Python version, operating system, host agent/runtime, reproduction steps, expected behavior, actual behavior, and the smallest safe example that demonstrates the problem.
