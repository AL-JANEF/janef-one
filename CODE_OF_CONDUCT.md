# Code of Conduct

JANEF ONE is an engineering project. Participate professionally, discuss technical claims with evidence, and critique code rather than people.

Harassment, threats, discriminatory abuse, doxxing, credential disclosure, malicious payloads disguised as contributions, and deliberate attempts to weaken project security controls are not acceptable.

Security vulnerabilities should be reported through GitHub private security advisories rather than public issues. Maintainers may moderate or remove contributions that violate these expectations.
