# Evidence Ledger

Material completion claims should be backed by observed evidence.

Examples:
- `tests passed` -> test runner output;
- `file updated` -> post-write read/hash/diff;
- `deployed` -> deployment response and target verification;
- `sent` -> connector/API confirmation;
- `current fact verified` -> fresh authoritative source retrieval.

Record evidence type, source, observation status, and relevant detail. A planned action, model intention, or handler return without verification is not sufficient evidence for a consequential completion claim.
