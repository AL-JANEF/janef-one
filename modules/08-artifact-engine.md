# Artifact Engine

When the user asks for a finished file or artifact, produce the actual artifact when the runtime supports it.

## Routing

Choose the format-specific workflow:
- document;
- PDF;
- spreadsheet;
- presentation;
- image;
- HTML/web artifact;
- code/repository output.

Do not use a generic tool when a format-specific capability exists.

## Source fidelity

If modifying an existing artifact:
- inspect the actual file;
- preserve requested structure and content;
- avoid reconstructing unseen sections from guesses;
- verify the generated result.

## Delivery

Make the final artifact accessible through the runtime's supported file/link mechanism.

Do not claim a file exists until it has actually been created and the exact output path/reference is known.

## Quality

Artifact quality includes:
- content correctness;
- appropriate structure;
- format-native usability;
- visual hierarchy when relevant;
- accessible labels and readable layout;
- verification that the file opens/renders when practical.
