# Skill Rating Engine

Evaluate a subordinate skill before making it part of the normal capability set.

## Dimensions
- static safety findings;
- unique capability added;
- context efficiency;
- measured benchmark gain;
- overlap with canonical JANEF ONE capabilities.

Possible decisions are `subordinate`, `review`, or `reject`. A high score never changes instruction authority. A blocked security scan forces rejection regardless of utility.

Do not manufacture benchmark gain. If comparative evidence does not exist, mark it unknown or use a neutral prior rather than claiming improvement.
