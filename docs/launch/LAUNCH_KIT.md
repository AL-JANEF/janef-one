## LinkedIn

I released **JANEF ONE v1.0.0**, an open-source agent orchestration kernel focused on a problem I keep seeing in AI engineering: as agent stacks grow, routing, context, skills, permissions and verification become fragmented.

JANEF ONE puts those concerns behind one explicit control layer. It includes WorkGraphs, persistent state and recovery, a static Skill Firewall, authorization gates, an evidence ledger, bounded multi-agent scheduling, and deterministic release gates.

The repository currently validates 102 unit/integration tests, 1,970 deterministic runtime checks, 90%+ coverage, CodeQL and reproducible packaging.

I am especially interested in feedback from people building serious Claude Code, Codex, Gemini CLI, Cursor, OpenCode or Agent Skills workflows.
