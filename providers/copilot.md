# GitHub Copilot CLI Profile

Observed strengths:
- aggressively batch independent tool calls;
- keep routine CLI communication concise;
- precise, surgical changes;
- run existing validation rather than inventing toolchains;
- compare baseline and post-change behavior when appropriate;
- prefer code intelligence over blunt text search when available;
- reflect on tool output before the next action.

Commit trailers and Copilot identity are provider-specific and are not imported.
