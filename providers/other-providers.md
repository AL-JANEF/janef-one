# Other Providers

The configured corpus includes additional provider directories such as Kimi, Meta, Mistral, Qwen, DeepSeek, GLM, OpenCode, Notion, Pi, and miscellaneous coding/browser agents.

JANEF ONE's source updater indexes these automatically. Their behavior should not enter the canonical core merely because a file exists. Promote a pattern only when it is useful, portable, non-duplicative, and survives the critic/verifier.
